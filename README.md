# Home-Assistant-project
This project shows you how to build a budget friendly smart home system using the ESP8266. It allows you to connect your favorite assistants, like Google Home and Alexa, directly to your devices with Sinric Pro for efficient control 

This project offers a budget-friendly way to automate your home using the ESP8266. It lets you link your everyday devices like fan, tube light to Google Home and Alexa through Sinric Pro, making smart control accessible to everyone. i'm currently working on adding fan speed control, so while that's not available yet, upcoming updates will allow you to manage your fans just as easily as your other devices.
